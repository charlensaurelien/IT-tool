  
# PowerShell Printer Monitoring and Troubleshooting Tool

## Project Overview

The project was developed using PowerShell to automate printer monitoring and troubleshooting. The script checks installed printers, tests network connectivity, monitors the Print Spooler service, identifies stuck print jobs, and provides basic troubleshooting suggestions. Printer status reports can also be exported to a CSV file.

## Problem

Teachers and school staff frequently experience printer issues, including offline devices, stuck print jobs, and network connectivity problems. Without a monitoring system, IT technicians must check each printer manually, which delays troubleshooting and disrupts daily school activities.

## Solution

I developed a PowerShell script that checks printer status, tests network connectivity, monitors the Print Spooler service, and identifies stuck print jobs. The script also provides troubleshooting suggestions and exports printer status reports.

## Result

The solution helps IT staff identify printer problems faster, reduce downtime, and improve support for teachers and school staff. It also demonstrates practical skills in PowerShell scripting, Windows administration, network troubleshooting, and IT automation.
